About Me

Halo, perkenalkan nama Grandhaart. Saya adalah seorang pemula yang sedang mempelajari dunia web development. Saat ini saya sedang belajar membuat website menggunakan HTML, CSS, dan JavaScript.

Saya tertarik dengan dunia teknologi karena perkembangan teknologi semakin cepat dan memberikan banyak peluang. Salah satu bidang yang ingin saya pelajari lebih dalam adalah pemrograman website.

Sebagai seorang pemula, saya menyadari bahwa masih banyak hal yang harus saya pelajari. Oleh karena itu, saya selalu berusaha untuk belajar dan mencoba hal-hal baru. Saya percaya bahwa kemampuan dalam pemrograman dapat berkembang melalui latihan dan pengalaman.

Tujuan Saya

Tujuan saya belajar web programming adalah agar dapat membuat website yang menarik, sederhana, responsif, dan mudah digunakan. Saya ingin memahami bagaimana sebuah website dibuat mulai dari tampilan hingga fungsi yang ada di dalamnya.

Bahasa Pemrograman yang Dipelajari

  • HTML untuk membuat struktur website.
  • CSS untuk mengatur tampilan website.
  • JavaScript untuk membuat website lebih interaktif.

Harapan Saya

Saya berharap dapat terus meningkatkan kemampuan saya dalam bidang web development. Saya ingin mendapatkan pengalaman melalui berbagai proyek dan dapat membuat website yang bermanfaat bagi orang lain.

Bagi saya, belajar pemrograman bukan hanya tentang menghafal kode, tetapi juga tentang memahami cara memecahkan masalah. Karena itu, saya tidak akan berhenti belajar dan akan terus mengembangkan kemampuan saya di bidang teknologi.
